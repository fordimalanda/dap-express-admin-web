# 📊 Dap-Express Admin Web Dashboard

Dashboard d'administration web moderne et réactif pour la gestion complète de votre boutique e-commerce.

## 🌟 Fonctionnalités
- Tableau de bord en direct avec indicateurs de performance clés (Revenus, Commandes, Taux de livraison).
- Graphique des ventes par jour et volume financier (Recharts).
- Gestion des commandes en temps réel (changement de statut, consultation des coordonnées client, filtres).
- Gestion du catalogue produits (création, modification, upload d'images, liens tracking pour campagnes Ads).
- Authentification sécurisée par Token JWT.

## 🛠️ Démarrage

```bash
# Installation
npm install

# Démarrage développement (Port 3002)
npm run dev

# Build production
npm run build
npm start
```
